1How to read this

AnuRupa is not a matrimony portal. Portals like Shaadi.com or BharatMatrimony are self-service: members register themselves, search themselves and pay a subscription. AnuRupa is a consultant-led tool — Anupama holds the book, does the matching, and shares a curated shortlist. That distinction drives everything below, because the two models are priced very differently.

Three market segments are relevant:

  • Matrimonial software / scripts (India) — productised portals sold as a one-time licence.
  • Matchmaker CRM (international) — subscription tools for professional matchmakers. Closest in purpose to AnuRupa.
  • Bespoke build — what AnuRupa is: built to one agency's workflow, source code owned.

6Where this leaves the pricing

AnuRupa is narrower than a ₹3.5 L portal — no apps, no payments, no member self-service — but it is bespoke rather than a configured template, it carries workflow that none of the portal products offer, and the source code is owned outright with no annual licence.

  • Above a basic script (₹50 k – ₹1.2 L), which is a template with no bespoke workflow.
  • Around the Starter / clone band (₹1.5 L – ₹3 L), which is where custom-fitted software sits.
  • Below Growth (₹3.5 L), which buys a mobile app and payment gateway that AnuRupa does not need.

Against a subscription CRM, a one-time build pays for itself quickly: SmartMatchApp Advanced alone is roughly ₹1.05 L every year, with no source code and no bespoke workflow at the end of it.
