Prices — pay-as-you-go list rates for Azure Central India and AWS Mumbai (ap-south-1), read from each provider's pricing API on 6 October 2026; no reserved-instance discounts applied, which would cut compute by roughly 30–40%. 2Optional: web application firewall at the edge

Neither total includes a WAF. It is not required — the platform enforces its access rules on the server, keeps the database off the public internet and serves photographs only through expiring signed links — but it is the usual next layer, and it is where the two clouds part company.

Azure's managed rule sets are a Front Door Premium feature — Microsoft's documentation states that "for Azure Front Door Standard, only custom rules are supported" — so matching AWS's protection on Azure costs roughly 48× more, and over ten times the rest of the bill.

Recommendation — AWS Mumbai. On the running cost alone the two are within ₹300 a month of each other and either would be a sound choice. The deciding factor is the firewall: a managed OWASP rule set costs ₹864/month on AWS and ₹41,995/month on Azure, because Azure only sells managed rules with its Premium edge tier. Budget ₹3,200/month without a WAF, or ₹4,050/month with one, on AWS.

Not included — domain registration (~₹1,000/year), any email or WhatsApp Business API charges, and the ₹2,000/hour maintenance rate quoted separately. Scaling — these figures hold to roughly 25,000 profiles and 100 GB of media; past that the database tier grows first, about ₹1,700/month per step. Caveat — list prices and the exchange rate move, so treat these as accurate at the date shown rather than as a fixed quotation. The client holds the cloud account and pays the provider directly.
